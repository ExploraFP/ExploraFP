# Copias de seguridad de Contenidos

Una carpeta por fecha (`AAAA-MM-DD/`) con todos los documentos de la base de datos de Contenidos
(https://claude.ai/artifact/1j6EgNthf9zB8n8rfSqa5t), un JSON por documento y una carpeta por colección:
carruseles, ops, ideas, fotos (solo las fichas; los archivos de imagen están en el almacén del artifact), calendario, config, ejemplos.

La hace cada lunes la tarea programada «Copia semanal Contenidos». Para recuperar algo: pedirle a Claude que restaure
el documento (o la colección) desde la carpeta de la fecha que se quiera, con ArtifactData set/batch.
